# Git 작업 규칙

## 변경사항 확인
- 작업 전후 `git_status`로 기존 변경사항을 확인한다.
- 다른 작업의 미커밋 변경사항은 임의로 포함하거나 되돌리지 않는다.
- 커밋은 기능 또는 목적별로 묶고 변경 파일의 범위를 검토한다.

## 커밋과 Push
- 커밋 메시지는 핵심 변경사항을 한글로 요약한다.
- Git push는 사용자가 명시적으로 요청한 경우에만 수행한다.
- 푸시 전 변경 범위와 검증 결과를 확인한다.
